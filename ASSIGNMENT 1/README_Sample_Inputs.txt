JAVA ASSIGNMENT 1 - SIMPLE SCANNER PROGRAMS
=============================================

Each Task folder contains one independent Java program. Save/compile/run each
program separately. The public class name matches the file name.

Compile and run:
    javac Task01.java
    java Task01

Repeat in the relevant Task folder.

NOTES
-----
- Tasks 1 and 2 are mainly analysis/design questions in the assignment; these
  small programs demonstrate the objects and data representation.
- Task 3 keeps the allocation logic from the assignment's Complete the Code
  section, but accepts the floor/slot/vehicle data through Scanner.
- Task 8 demonstrates the same rates as the assignment's expected output:
  TwoWheeler Rs 30, Car Rs 90, ElectricCar Rs 210 when minutes=130 and
  charging units=10.
- Task 12 is a simple demonstration of the changed vehicle types and one-day
  pass. The assignment does not provide a fixed sample output for this task.
- These are beginner-level task demonstrations, not one fully integrated
  production parking application. Add the written analysis, pseudocode,
  UML, complexity discussion and testing evidence separately as required.
